# GUI 用例列表布局调整设计

日期: 2026-09-21
状态: 已确认(用户批准)

## 背景与问题

2026-09-21 上线的多用例批量执行功能把用例列表做成了**左侧独立面板**
(顶层 `QSplitter` 左右分栏,左 240px 用例列表 / 右侧编辑主区)。
用户反馈不合理:用例列表应与测试步骤详情保持同一列显示,不应左侧单独占一列。

## 目标布局

窗口恢复单一垂直列,自上而下:

```
工具栏: 保存/另存为/预览 | 次数[1] ▶运行 ■停止
──────────────────────────────────────────
设备 [MuMu模拟器▾] ↻ | 测试APP[ ] 🔍检测 设备名称[ ]   ← 环境条(不动)
──────────────────────────────────────────
┌──────────────┬────────────────────────┐
│ 全选 | 清空    │ 组[ ] 用例[ ] 优先级[P0]      │  ← 新增左右并排行
│ ☑全局清扫     │ 间隔s[5] | 快捷动作按钮…       │
│ ☑划区清扫 …  │                             │
└──────────────┴────────────────────────┘
──────────────────────────────────────────
           步骤详情卡片区                    ← 不动
──────────────────────────────────────────
           日志 / 运行结果区                  ← 不动
```

- **左**:用例列表面板,紧贴设备下拉框正下方
- **右**:现有 chip 条(组/用例/优先级/间隔s + 快捷动作按钮),内容不动
- 左右并排行插在环境条之下、卡片区之上

## 实现要点(`gui/main_window.py`)

1. **删除顶层 `QSplitter`**:`__init__` 里 `split = QSplitter(...)`
   及 `setCentralWidget(split)` 改为直接 `setCentralWidget(page)`。
2. **中间行组装**:新建容器 `QWidget` + `QHBoxLayout`:
   - 左:`_build_case_list()` 返回的面板
   - 右:`_build_chip_strip()`(stretch=1 占满余宽)
   - 该行插入 `v.addWidget(_build_env_strip())` 与卡片区之间。
3. **用例列表面板规格**:
   - 标题行:「全选」「清空」小按钮(沿用现有逻辑)
   - 列表:`QListWidget` 复选框行,**固定宽度约 200px**(与设备下拉框视觉对齐),
     **固定高度约 5 行可见 + 内部滚动**(12 个用例不必全部展开)
4. **交互语义全部不变**:
   - 勾选 = 参与批量执行(`_checked_case_files()` 逻辑不动)
   - 单击行 = 右侧显示该用例步骤(选中信号不动)
   - 全选/清空、次数轮跑、运行/停止、`RunWorker(case_files, repeat)` 不动

## 错误处理

无新增错误路径——纯布局重排,所有信号槽连接保持原样。
